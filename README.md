# Cinema — “Jashtyk” Movie Theater 🎬🍿

**Cinema — “Jashtyk”** is a web project that represents a cinema website for a local movie theater.  
The platform includes movie listings, showtimes, contact details, and simple ticket information.  
It also showcases a basic **admin interface** for managing films and sessions. :contentReference[oaicite:1]{index=1}

## 🔗 Live Demo
🌐 Website: https://skkiak.github.io/cinema/

## 🧠 Project Overview
This project displays a modern cinema landing page and scheduling system. Visitors can:
- see upcoming films and showtimes,  
- view contact information and ticket options,  
- reach out via WhatsApp for booking or inquiries.  
It also includes a basic admin view for adding movies and sessions. :contentReference[oaicite:2]{index=2}
